# Visual board production notes

Tool: `image_gen.imagegen`. Three image-based visual explorations were generated using the captured live homepage as a reference. The reusable briefs below restate the final direction constraints; they are not a verbatim transcript of the generation calls.

## A — Modern Landworks

Create a high-fidelity P1 Land & Property Management website concept for substantial Carolina working properties. Use a bright off-white canvas, precise bold sans typography, large documentary land/equipment imagery, an open numbered capability index, restrained P1 blue calls to action and hairline section divisions. Test land/water/site-work positioning before seasonal grounds services. Include a desktop homepage and mobile composition. Avoid contractor-template gradients, rounded card grids, fake testimonials, invented equipment ownership and fabricated project statistics. Clearly label the board as a design exploration.

## B — Commercial Field Operations

Create a distinct P1 visual direction for commercial managers and working-land owners. Graphite canvas, compact operational hierarchy, scope-led hero, tabular capability rows, landscape equipment imagery and precise process communication. Preserve P1 identity and blue primary actions. Make scale legible without unsupported fleet or service-level claims. Include desktop and mobile views. Keep imagery illustrative, with no fabricated completed P1 projects, fabricated reviews or precise project outcomes.

Saved result: `b-commercial-field-operations.png`. Original tool result: `exec-a76a327b-cd62-4a08-a429-46c8068bd9e8.png`.

## C — Carolina Land Specialists

Create a distinct regional P1 direction: pale linen and restrained ochre surfaces, expansive Carolina working-land imagery, strong readable typography, quiet horizontal rhythm and approachable acreage positioning. Keep P1 blue for functional calls to action. Avoid rustic decorative type, resort-landscaping cues and invented offices or territory boundaries. Include desktop and mobile compositions. No fictional project facts or testimonials.

Saved result: `c-carolina-land-specialists.png`. Original tool result: `exec-ca953497-2e26-4024-8e00-aba48e52eddd.png`.

## Review boundary

These boards establish atmosphere and composition. Incidental generated copy, dates, map marks and colour drift are not factual or implementation specifications. In particular, the C HTML uses blue actions even where its generated board drifts. Use the editable screen set and design decisions for exact content and behaviour. Existing illustrations remain explicitly separate from actual P1 work.
