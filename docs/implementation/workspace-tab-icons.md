# Client and property workspace tab icons

Every client and property workspace tab now pairs its existing label with a decorative Lucide icon in a tinted badge. Shared destinations use the same icon and color across both workspaces. Labels and the active underline remain the primary navigation cues; icons are hidden from assistive technology. The existing tab permissions, routes, and mobile horizontal scrolling are preserved.

Validation: dashboard TypeScript check and production build; no API, data, or authorization changes.
