# Property card maps

Overview property cards reuse the existing Properties page Positron map style and validated property coordinates. Each card centers its blue location marker at zoom 16 (block-level context). The old decorative corner pin and topo background are removed; acreage remains overlaid at the top right. Card maps do not intercept pan/zoom gestures; attribution remains available and the property information button opens the workspace. Missing coordinates show a clear unavailable message instead of an invented location. No address geocoding or persisted-data changes are involved.
