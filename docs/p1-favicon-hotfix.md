# P1 favicon production hotfix

The September 7, 2026 owner request authorizes immediate publication of the supplied P1 symbol. The prior production deployment `1aa77d7b-aa2f-435e-bd68-58c9a462dc71` still served a 163-byte orange placeholder at `/favicon.svg`, despite the correct SVG already existing in the repository.

## Scope and provenance

Patch revision `79ac6803c51ca8f8b88b5f32e0164fc59d12623a` adds versioned SVG, PNG and ICO references plus an Apple touch icon. The supplied SVG is preserved byte for byte, SHA256 `6bc52ee42c8af55dcd60cea41fa38e5641ce74c319c1eff172343c4eeaf64761`. PNG/ICO derivatives use the existing Sharp 0.34.5 dependency with a white square background; ICO contains 16, 32 and 48 pixel images, PNG is 32 pixels, and the Apple icon is 180 pixels. No new dependency is introduced.

This is an overlay on the captured existing production runtime, not a deployment of the current full CMS migration branch. All 67 pre-rendered HTML files differ only in icon links. Existing public assets remain byte-identical except the replaced favicon and three added derivatives. The source index receives the same links for future builds. The existing Vite preview configuration and production port remain in use; its planned replacement is still part of the full website release. Direct Node execution of the captured Vite CLI replaces the package-manager launch wrapper without rebuilding pages or dependencies.
